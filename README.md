# 深渊回响 · ABYSS ECHO

一款纯前端 3D 动作肉鸽（Roguelike）游戏，基于 Three.js，无需后端、无需安装。

## 在线试玩

👉 **https://nonamedcy.github.io/abyss-echo/**

## 玩法

深入 20 层地下城，每 5 层迎战一位首领。每层清空敌人后进入传送门前往下一层，升级时从三项随机祝福中选择一项构筑 Build。

| 生态区 | 层数 | 首领 |
| --- | --- | --- |
| 腐朽地窖 | 1–5 | 腐骨看守者 |
| 翡翠墓穴 | 6–10 | 翠魂守墓人 |
| 熔火深渊 | 11–15 | 熔核暴君 |
| 虚空王座 | 16–20 | 虚空之王 · 厄瑞玻斯 |

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` | 移动 |
| `鼠标` | 瞄准 |
| `左键` | 射击（按住连发） |
| `空格 / Shift` | 冲刺（带无敌帧） |
| `右键 / Q` | 灵魂新星（范围爆发，清弹） |
| `F` | 切换自动射击 |
| `1 2 3` | 选择祝福 |
| `R` | 重掷祝福（每局 3 次） |
| `ESC` | 暂停 |

## 内容

- **5 种敌人**：追击者、远程施法者、冲锋兵、自爆兵、首领；第 6 层起出现金色精英
- **4 种首领 AI**：螺旋弹幕、追击突进、环形爆发、召唤、跳砸冲击波；半血进入狂暴二阶段
- **24 项祝福**：4 档稀有度（普通 / 稀有 / 史诗 / 传说），含多重射击、穿透、暴击、吸血、反弹、霜冻、点燃、追踪弹、环绕灵刃、雷链、尸爆连锁、不死鸟复活等
- **手感**：顿帧、震屏、伤害飘字、粒子池、冲击波、程序化合成音效（无音频资源）

## 技术

- 单页静态站点，无构建步骤，无外部依赖（Three.js r149 已本地化）
- 程序化生成：地板贴图、石柱布局、符文阵、粒子与音效均为运行时生成
- 存档：`localStorage` 记录最佳层数

## 本地运行

直接双击 `index.html` 即可。若浏览器限制本地文件，可起一个静态服务器：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```
