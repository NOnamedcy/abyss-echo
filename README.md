# 深渊回响 2.2.1 · ABYSS ECHO

一款纯前端 3D 动作肉鸽（Roguelike）游戏，基于 Three.js，无需后端、无需安装。

主角为银紫双马尾的 Q 版女法师。标题展示角色原画，战斗使用四向贴图。四类常见敌人采用同风格插画，立绘与贴图均内嵌在离线游戏中。

## 玩法

地下城共 40 层。清场后选取祝福，再进入传送门。击败第 20 层的无相之王后，可以返回地表结算、继续向下挑战，或带一件遗物用同一个种子重演。第 40 层先迎战报幕人，再挑战三阶段的无貌歌者。

开局可选雷鸣、余烬或霜锋法印。普攻留下元素印记，霜缚、余烬和雷链祝福可附加其他元素。对带异元素印记的敌人释放法印技，可以触发霜火碎裂、电霜或雷火爆燃。

第 2、7、12、17、22、27、32、37 层可挑战权柄试炼，胜利后额外选择祝福。第 3、8、13、18 层和指定深层关卡可进入幽库，靠近任一宝箱选取遗物。

不同种子会生成不同的布局、敌人编成和环境词条。收集三件同系遗物触发共鸣。锋、霜、雷三条构筑路线各有两档被动，按已选祝福种类计算。第 3 层解锁守护技，第 8 层解锁追猎技，每个技能槽有两种变体。

| 生态区 | 层数 | 首领 |
| --- | --- | --- |
| 腐朽地窖 | 1–5 | 锈冠典狱长 |
| 翡翠墓穴 | 6–10 | 翡翠织骸者 |
| 熔火深渊 | 11–15 | 熔炉暴君 |
| 虚空王座 | 16–20 | 无相之王 |
| 星屑温室 | 21–25 | 孢母 · 缇娅 |
| 潮汐回廊 | 26–30 | 潮汐主教 · 涟 |
| 熔核工厂 | 31–35 | 熔核工头 · 铆钉 |
| 梦魇剧场 | 36–40 | 报幕人 · 帷、无貌歌者 |

温室的藤蔓可被射击破坏，潮汐回廊的浅色浮台可以避开涨潮。工厂的传送带会推动双方，剧场的扫射灯光会暴露玩家。每个新区入口会显示机制提示。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` | 移动 |
| `鼠标` | 瞄准 |
| `左键` | 射击（按住连发） |
| `空格 / Shift` | 冲刺（带无敌帧） |
| `右键 / Q` | 法印技（范围爆发，清弹，可触发元素融合） |
| `E` | 守护技 |
| `V` | 追猎技 |
| `F` | 切换自动射击 |
| `1 2 3` | 选择祝福 |
| `R` | 重掷祝福（每局 3 次） |
| `ESC` | 暂停 |

手机和平板可拖动左下摇杆移动，默认开启自动瞄准。按住战场可手动瞄准射击，点按右下按钮释放技能。祝福、遗物和重掷均可直接点按。

## 内容

- **9 位首领**，包括四位深层区域首领和终局首领。盾卫、咒缚者、珊瑚炮台、铆钉机甲等敌人有独立的攻击或防御方式。
- **33 项祝福与 24 件遗物**。保留原有 25 项祝福，增加破甲、处决、霜棱等构筑选择。
- **局内存档与回响祭坛**。进入新层或清场开启传送门时自动归档，标题页可继续。结算取得的回响点可解锁跨局能力。

## 技术

- 单页静态站点，无构建步骤，无外部依赖（Three.js r149 已本地化）
- 程序化生成：地板贴图、石柱布局、符文阵、粒子与音效均为运行时生成
- 存档：`localStorage` 保存进度、纪录和祭坛解锁。不同浏览器与不同网页来源各有独立存档。
- 自检：为游戏地址添加 `?selftest=1`，可查看布局、难度、构筑和存档断言。

## 本地运行

直接双击 `index.html` 即可。若浏览器限制本地文件，可起一个静态服务器：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```
