# 深渊回响 2.1 · ABYSS ECHO

一款纯前端 3D 动作肉鸽（Roguelike）游戏，基于 Three.js，无需后端、无需安装。

## 在线试玩

👉 **https://nonamedcy.github.io/abyss-echo/**

## 玩法

深入 20 层地下城，每 5 层迎战一位首领。每层清空敌人后进入传送门前往下一层，升级时从三项随机祝福中选择一项构筑 Build。

开局可选雷鸣、余烬或霜锋法印。普攻留下元素印记，霜缚、余烬和雷链祝福可附加其他元素。对带异元素印记的敌人释放法印技，可以触发霜火碎裂、电霜或雷火爆燃。

第 2、7、12、17 层清场后，可直接进入传送门，也可挑战权柄试炼。击败精英和随从可额外挑选一次祝福，优先提供史诗或传说选项。

| 生态区 | 层数 | 首领 |
| --- | --- | --- |
| 腐朽地窖 | 1–5 | 锈冠典狱长 |
| 翡翠墓穴 | 6–10 | 翡翠织骸者 |
| 熔火深渊 | 11–15 | 熔炉暴君 |
| 虚空王座 | 16–20 | 无相之王 |

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` | 移动 |
| `鼠标` | 瞄准 |
| `左键` | 射击（按住连发） |
| `空格 / Shift` | 冲刺（带无敌帧） |
| `右键 / Q` | 法印技（范围爆发，清弹，可触发元素融合） |
| `F` | 切换自动射击 |
| `1 2 3` | 选择祝福 |
| `R` | 重掷祝福（每局 3 次） |
| `ESC` | 暂停 |

手机和平板可拖动左下摇杆移动，默认开启自动瞄准。按住战场可手动瞄准射击，点按右下按钮使用冲刺或法印技。祝福和重掷均可直接点按。

## 内容

- **5 种敌人**：追击者、远程施法者、冲锋兵、自爆兵、首领；第 6 层起出现金色精英
- **4 种首领 AI**：螺旋弹幕、追击突进、环形爆发、召唤、跳砸冲击波；半血进入狂暴二阶段
- **25 项祝福**：4 档稀有度（普通 / 稀有 / 史诗 / 传说），含多重射击、穿透、暴击、吸血、反弹、霜冻、点燃、追踪弹、环绕灵刃、雷链、尸爆连锁、不死鸟复活等
- **手感**：顿帧、震屏、伤害飘字、粒子池、冲击波、程序化合成音效（无音频资源）

## 技术

- 单页静态站点，无构建步骤，无外部依赖（Three.js r149 已本地化）
- 程序化生成：地板贴图、石柱布局、符文阵、粒子与音效均为运行时生成
- 存档：`localStorage` 记录最佳层数

## 本地运行

直接双击 `index.html` 即可。若浏览器限制本地文件，可起一个静态服务器：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```
